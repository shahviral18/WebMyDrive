# WebMyDrive PHP Backend

A complete PHP 8.1+ backend replacing the Node.js/TypeScript/Express backend.
**Zero external library dependencies.** All logic is implemented natively.

## 🚀 Setup Instructions

### Prerequisites
- **PHP 8.1+** with extensions: `pdo`, `pdo_sqlite`, `curl`, `json`, `openssl`
- **Apache** (with `mod_rewrite`) or **Nginx**
- The existing **SQLite database** at `server/prisma/dev.db` (generated by Prisma)
- Run `npx prisma migrate deploy` inside `server/` first to ensure the schema is up to date

### Step 1 — Configure environment

```bash
cd server-php
copy .env.example .env
```

Edit `.env` and set:
- `JWT_SECRET` → same value as in the Node.js `.env`
- `DB_PATH` → absolute path to `server/prisma/dev.db`
- `RAZORPAY_KEY_ID` / `RAZORPAY_KEY_SECRET` → leave blank for demo mode

### Step 2 — Web Server Setup

**Apache** (recommended):
```apache
<VirtualHost *:80>
    ServerName localhost
    DocumentRoot "/path/to/server-php/public"
    <Directory "/path/to/server-php/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

Make sure `mod_rewrite` is enabled:
```
a2enmod rewrite
```

**Nginx**:
```nginx
server {
    listen 80;
    root /path/to/server-php/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

**Quick test with PHP built-in server** (development only):
```bash
cd server-php/public
php -S localhost:4000
```

### Step 3 — Ensure logs directory is writable

```bash
mkdir -p server-php/logs
chmod 755 server-php/logs
```

### Step 4 — Update frontend API base URL

If your frontend points to `http://localhost:4000`, no change needed.
For production, update `VITE_API_URL` in the frontend `.env`.

## 🔐 Security

- **JWT**: HS256, same secret as Node.js — tokens are **cross-compatible**
- **Passwords**: `password_hash(PASSWORD_BCRYPT, cost: 10)` ← same as Node.js `bcrypt`
- **SQL Injection**: All queries use PDO prepared statements — zero raw interpolation
- **CORS**: Configured via `ALLOWED_ORIGINS` env variable
- **Input sanitization**: All `$_GET`, `$_POST`, JSON body — sanitized in `Request.php`

## 🧪 Demo Mode

When `RAZORPAY_KEY_ID` / `RAZORPAY_KEY_SECRET` are not set (or contain placeholders),
the backend automatically enters **demo mode**:
- Orders are created normally
- `rzpOrderId` returns `demo_order_...`
- Payment verification accepts any `payment_id` starting with `demo_pay_`

## ⚡ PHP vs Node.js Key Differences

| Concern | Node.js | PHP |
|---------|---------|-----|
| JWT | `jsonwebtoken` npm | Pure PHP HS256 (compatible) |
| Password hash | `bcrypt` npm | `password_hash(BCRYPT)` (identical) |
| Database | Prisma ORM | PDO prepared statements |
| HTTP client | `axios` / `node-fetch` | PHP cURL |
| Google OAuth | `google-auth-library` | Google tokeninfo endpoint |
| Background jobs | BullMQ + Redis | Inline (no queue required) |
| Shared memory | In-process Map | Audit log (persistent fallback) |
